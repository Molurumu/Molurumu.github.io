# Molurumu.github.io

Personal portfolio site for **Molurumu**, designed for GitHub Pages.

## Structure

- `/index.html` — page content and section structure
- `/styles.css` — visual theme and responsive layout
- `/script.js` — mobile navigation toggle and small UI behavior
- `/CNAME` — custom domain configuration

## Quick content edits

Update the following in `/index.html`:

- Hero intro text and CTA labels/links
- About paragraph
- Project titles, descriptions, tech tags, and links
- Skills list
- Contact links and email address

Also update metadata in the `<head>` (`title`, description, Open Graph values) to match your final branding.

## Local preview

Because this is a static site, you can preview with any local static server. For example:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Deployment

This repository is compatible with GitHub Pages static hosting as-is.
